# Tensegrity Structure Force Visualization

## 概要
テンセグリティ構造（引張材＋圧縮材）の節点配置を視覚化し、内力分布（テンションとコンプレッション）をリアルタイムで表示するインタラクティブビジュアライザー。

## 機能
- Canvas上にテンセグリティ構造を2D描画
- 4種類のプリセット構造: Simplex（3本ストラット）・Double Layer（6本）・X-Module・Prism（4本）
- 圧縮材（ストラット）: 青い太線、引張材（ケーブル）: 赤い細線で表示
- 線の太さ/色の濃さ ∝ 力の大きさ（バネモデルで計算）
- 節点をドラッグして構造を変形 → 力分布がリアルタイム更新
- 平衡状態チェック: 各節点の合力が小さい場合は「Equilibrium」バッジ表示
- 右パネル: ストラット数・ケーブル数・節点数・最大力・プレストレス合計を表示
- 全メンバーの力の大きさをバーグラフで一覧表示
- ラベルON/OFFでメンバー番号・力の値を表示切り替え
- Buckminster Fullerのテンセグリティ原理の説明パネル

## 使い方
1. 上部ボタンで構造を選択（Simplex / Double Layer / X-Module / Prism）
2. 青い節点をドラッグして形状を変形
3. 右パネルで各メンバーの力を確認
4. `Labels` ボタンで力の数値ラベルをON/OFF
5. `↺ Reset` で初期形状に戻す

## 技術スタック
- Pure HTML/CSS/JavaScript
- Tailwind CSS (CDN)
- Canvas 2D API によるリアルタイムレンダリング
- バネモデルによる力計算
